# CypherClash API

## Setup

1. Install MongoDB and start it locally, or provision a MongoDB deployment.
2. From this directory, install dependencies:

   ```bash
   npm install
   ```

3. Copy `.env.example` to `.env` and set every required value. Keep `.env` private.
4. Seed the admin account:

   ```bash
   npm run seed
   ```

   Set `SEED_SAMPLE_TEAMS=true` in `.env` before running the command if three sample teams and one-time credentials should also be created.

## Run

Development mode:

```bash
npm run dev
```

Production mode:

```bash
npm start
```

The API listens on `PORT` and exposes `/api/health`, which returns `{ "ok": true }`.

The browser must send requests with credentials enabled because authentication uses an httpOnly session cookie. Configure the exact frontend URL with `FRONTEND_ORIGIN`.

## Security notes

- Only bcrypt hashes are stored for player and admin passwords.
- Passwords generated by team creation and password reset are returned once and are never logged.
- Sessions are stored in MongoDB and expire after 12 hours.
- Player and admin authorization is derived from the server-side session role.
- Login requests are limited by IP and, for players, by team ID.
